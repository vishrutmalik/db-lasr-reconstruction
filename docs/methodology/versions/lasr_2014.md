# Version spec — `lasr_2014` (LASR baseline, P3, 2014-12-01)

Executable configuration for the third-generation monthly LASR model, from
P3 evidence (`docs/evidence/p3_lasr_2014/`). Defining change vs 2012/2013:
the **linearized (triangular-membership) weak learner** (CR-007). P3's
algorithm boxes (Figs 6/21) are unreadable; boosting mechanics not restated
in P3 text are IMPORTED_FROM_P1, never presented as stated by P3.
Sibling specs: `lasr_hc_2014.md`, `lasr_hf_2014.md` (deltas only).

## 1. Universe and eligibility

- Russell 3000 (US), S&P/TSX Composite (Canada), S&P BMI elsewhere;
  nine mutually exclusive regions per Fig 29 with start dates (US
  1987-12-31 … LATAM/Em-EMEA 1995-10-31) (P3-04; CR-015).
- One model per region; pooling across regions explicitly rejected
  (P3-05).
- Eligibility: index membership only; nothing else disclosed (P3-37).

## 2. Clocks

- Monthly rebalance; "re-fitted every month, only using data available as
  of" the training date (P3-08).
- Execution: same-close convention for monthly variants; next-open
  sensitivity check recommended (P3-30; CR-018).

## 3. Features and preprocessing

- Feature set: the 70 factors named in Fig 2, six styles (P3-21; CR-016).
  Formulas by reference to the QCD library → our definitions ASSUMED
  (shared with A-G011-03).
- Preprocessing: normalized and outlier-adjusted by reference (method not in
  P3 → IMPORTED_FROM_P1 rank/N pipeline; the p.45 uniform-[0,1] transform is
  the horse-race setup, not necessarily production — extraction §Feature
  preprocessing ambiguity).
- Neutralization (CR-004): within-group ranking AND within-group 30/30
  labels; US = sector×size×beta (median splits, float-adjusted cap for
  size); other regions = country and/or sector; thin countries grouped into
  regions (P3-20). Cell nesting order NOT_DISCLOSED → ASSUMED full cross
  as in P2 (A-G011-30).

## 4. Target and labels

- Horizon: 1-month forward return (P3 pp.5–6; CR-006).
- Performance in USD; label currency NOT_DISCLOSED → USD ASSUMED
  (P3 Q8, A-G011-08).
- Labels: within-group top 30% = +1 / bottom 30% = −1 / middle 40%
  disregarded from fitting; all stocks scored at prediction (P3-06).
- Vol scaling: none at signal level (extraction §Volatility scaling).
- No overlapping labels (1M/monthly); walk-forward invariant per P3-08.

## 5. Weak learner (triangular linearized; P3 formulas.md §3 — EXPLICIT)

- Percentile rank p(x) ∈ [0,100]; bin centers c_j = (100/Q)(j−½), width
  ω = 100/Q; for Q=5: centers (10,30,50,70,90).
- Membership: m_j(x) = max(0, 1 − |p(x)−c_j|/ω) — triangular, at most two
  adjacent bins nonzero ("linear interpolation for two connected
  quintiles", P3 p.17; P3-11).
- Training masses: W±ⱼ = Σ_{y=±1} w(x)·m_j(x) — fractional (paper's
  45th-percentile example: 25%/75%; P3-12; verified P3 formulas §3.2).
- Prediction: h(x) = Σⱼ ½·ln((W⁺ⱼ+ε)/(W⁻ⱼ+ε))·m_j(x) — continuous,
  piecewise-linear (P3-11).
- Tail handling BEYOND outer centers NOT_DISCLOSED (membership sums <1;
  P3 Q1): config `tail_mode ∈ {literal, clamp}`, default `literal`
  (the printed formula), ASSUMED (A-G011-31). Sensitivity test required.
- ε: role EXPLICIT, value NOT_DISCLOSED (P3-14) → 1/N IMPORTED_FROM_P1
  (CR-011).
- Q: 5 ("equals to five in our case", P3-13); per-region override Q=3 for
  EUxUK/Japan/AxJ (INFERRED from Figs 121–124 tercile axes; CR-012,
  A-G011-32).

## 6. Factor-selection objective

- P3 qualitative only ("add incremental predictive power", p.8) →
  argmin-Z IMPORTED_FROM_P1 (CR-008), computed on the FRACTIONAL masses
  (INFERRED: Z's inputs are whatever W±ⱼ the kernel defines; A-G011-33).

## 7. Weight update

- P3 qualitative only → w·exp(−y·h) IMPORTED_FROM_P1 (CR-009), with h now
  the continuous linearized prediction. "Correctly classified" needs no
  separate definition under this update (sign and magnitude both enter via
  y·h; P3 Q2 resolved by the P1 formula). Renormalize each round.

## 8. Rounds and stopping

- NOT_DISCLOSED in P3; L=30 IMPORTED_FROM_P1 (CR-010). P3's "beyond 10 or
  20 … minimal" (P3-15) handled by the CR-010 sensitivity test
  (n_rounds ∈ {20,30}) and a distinct-factor-count diagnostic.

## 9. Ensemble (4 components — CR-002/003/005)

- Samples: rolling 12m; rolling 12y same calendar month (CR-027: most
  recent 12, footnote example is an erratum); previous 1m; hedge = months
  in the past 10 years where the baseline was in the bottom half of
  performance (P3-17; metric = trailing model rank IC, INFERRED —
  A-G011-34; CR-003).
- Weighting: equal weight default — LASR final model "essentially an
  average" (P3-19); US dynamic recent-performance mode selectable
  (P3 p.9 fn.6; CR-005). Hedge weight rule: `equal` default for this
  version (P3 wording), `mean_of_others_then_normalize` selectable
  (P2 rule) — configurable, difference is immaterial when base weights are
  equal (both give 1/4).
- Prediction: strong classifier = raw sum of weak classifiers, used as a
  composite factor; no z-scoring disclosed at combination for LASR
  (P3-35) → per-component z-scoring IMPORTED_FROM_P1 before averaging
  (A-G011-35; needed for commensurability, flagged as import).

## 10. Portfolio, constraints, costs

- Analytics: quintile L/S, equal-weighted, monthly (P3 p.20); deciles in
  some exhibits.
- Optimized (P3-26/27): L/S market-neutral, 2x leverage, 4% target vol,
  max stock 1.5%, beta ≤0.1, sector ≤10%, country ≤10%, turnover 30%
  one-way/month; Axioma MH fundamental risk model + Axioma optimizer
  (P3-29; substitute per A-004 with MODERNIZED flag).
- Costs: 20 bps one-way base; realistic tiers 30/40/50 bps for US
  small-cap / Em EMEA / LATAM (P3-28; CR-013). Borrow: none (P3-36).
- Capacity harness: 10% of 20-day ADV cap; AUM $100M and $5B sims
  (P3-31).

## 11. Validation periods and acceptance targets

- Design split (P3-32): US in-sample 1987–mid-2012; mid-2012→2014 and all
  non-US treated as "true out-of-sample". Analytics 1996–2014 YTD;
  optimized from 1999 (LATAM end-2006).
- Acceptance targets (P3-33, Fig 44, after-cost optimized): US rank IC
  8.26%, risk-adj 1.56, Sharpe 2.50; EUxUK 8.70%/1.28/4.24; Japan
  9.53%/1.15/2.48; … ANZ 8.68%/0.72/1.50 (full table in P3 extraction).
- Linearization-specific acceptance (P3-25): score serial correlation
  higher than hard-bin N-LASR — paper: "43% and 16% higher than the
  N-LASR1 and N_LASR2"; plus the continuity/no-jump kernel tests (CR-007)
  and MASTER_PROMPT §17 synthetic invariant (hard-bin turnover > LASR
  turnover).
- Global blend (optional layer): equal-weight of 9 regional portfolios,
  Sharpe 5.5 reported (P3-38).
