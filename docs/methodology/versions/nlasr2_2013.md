# Version spec — `nlasr2_2013` (N-LASR2, P2, 2013-01-23)

Executable configuration for the second-generation model, from P2 evidence
(`docs/evidence/p2_nlasr2_2013/`). P2 states the ML engine is unchanged —
"same machine learning algorithm we used before" (P2 p.1; E-P2-02) — and
discloses NO AdaBoost parameters (Figure 7 unreadable). Every engine
parameter below is therefore marked IMPORTED_FROM_P1, never presented as
stated by P2 (CR-010/011/012). P2's own contributions: signal-level
neutralization cells and the hedge (different-market-conditions) classifier.

## 1. Universe and eligibility

- US: Russell 3000 (E-P2-03). Regions: 9-region scheme per Fig 54 (S&P BMI;
  Canada TSX-based; Global = union) with start dates/country lists
  (E-P2-04; CR-015).
- Activation: "over 100 stocks" start rule, applied to set the start date
  (INFERRED one-time; E-P2-05, P2 Q14).
- Canada extra cap/liquidity filters unquantified → ASSUMED thresholds if
  Canada is built (P2 Q11).
- Trained on Russell 3000, scored on sub-universes (e.g. Russell 1000)
  where required (E-P2-27).

## 2. Clocks

- Monthly rebalance and full monthly retrain of all four classifiers
  (E-P2-06, extraction §5 — both INFERRED from P2 text, consistent with P1).
- Execution: same-close zero-delay (INFERRED, extraction §36; CR-018).

## 3. Features and preprocessing

- Feature set: NOT disclosed by P2 → the P1 70-factor US library
  IMPORTED_FROM_P1 (CR-016; E-P2-23 context). The 8-factor list on p.41 is
  the benchmark comparison model only (E-P2-30), not N-LASR2 features.
- Preprocessing: per month, rank/N → (0,1] *within each neutralization
  cell* (E-P2-07/09; F-P2-1 verified against Fig 10). Rank 1 = highest raw
  value (Fig 10; extraction §10); the learner learns direction, no sign
  flips.
- Outliers: none beyond ranking (extraction §9).
- Missing values / ties: NOT_DISCLOSED → IMPORTED_FROM_P1 conventions
  (h=0 at predict, stable-sort ties).

## 4. Neutralization cells (P2 core contribution — CR-004)

- Mechanism: cell-wise rank normalization of factors AND cell-wise 30/30
  labeling of targets, one simultaneous categorical pass (NOT sequential
  residualization) (E-P2-09..13).
- Cell definitions: sector (10 sectors — GICS ASSUMED, P2 Q2); country;
  size = market cap vs median (E-P2-11; measure/date ASSUMED, P2 Q5);
  beta = 1-year beta vs median (E-P2-12; estimation spec ASSUMED, P2 Q4).
  US full scheme: 10×2×2 = 40 cells (F-P2-3).
- Per-region scheme (Fig 55, E-P2-15): US = sector+size+beta;
  Japan/Canada/UK = sector only; EUxUK/AxJ/EM/ANZ/Global = country only;
  all regions + hedge classifier.

## 5. Target and labels

- Horizon: 1-month forward return (E-P2-16); USD, currency unhedged
  (E-P2-17); total return ASSUMED (P2 Q10).
- Labels: within-cell top 30% = +1 / bottom 30% = −1 / middle 40% dropped
  (E-P2-08; F-P2-2 verified against Fig 10 energy cell; Fig 10 utilities
  labels are a printed anomaly — do not use as golden vector, F-P2-2 note).
- Forward returns are used only for within-cell labeling (CR-025).
- Vol scaling: none (extraction §15). No overlap → no purging needed
  (1M horizon, monthly cadence); walk-forward invariant as in nlasr_2012.

## 6. Weak learner / objective / update / rounds (all IMPORTED_FROM_P1)

- Kernel: hard-bin log-ratio h = ½·ln((W⁺ⱼ+ε)/(W⁻ⱼ+ε)) — P2 gives the
  qualitative description only (F-P2-4) → IMPORTED_FROM_P1 (P1-12).
- Q = 5, ε = 1/N, argmin-Z selection (unsmoothed Z), w·exp(−y·h) update,
  L = 30, fixed-count stop: all IMPORTED_FROM_P1 (P1-11/13/14/15/17;
  CR-010/011/012). Strong classifier H = Σh is EXPLICIT in P2 (F-P2-5).

## 7. Ensemble (4 components — CR-002/003/005)

- Samples: trailing 12m; trailing-12y same calendar month (fallback all
  available); previous 1m (E-P2-18) — plus the hedge sample:
  - Backcast the current-date model over each of the past 144 months;
    hedge months = backcast rank IC < 7.5% ("close to the average rank
    IC"); train the 4th classifier on those months pooled (E-P2-19/20;
    F-P2-7).
  - Backcast object = combined 3-classifier model (INFERRED, P2 Q8);
    hedge months pooled with equal weights (INFERRED, extraction §21).
- Combination: per-date z-score each classifier (E-P2-22); non-US equal
  weights; US = same-calendar-month average rank-IC weights
  (window NOT_DISCLOSED → expanding, IMPORTED_FROM_P1 convention
  A-G011-16); hedge weight = mean of the other three, then normalize —
  always exactly 25% (E-P2-21; F-P2-8 algebra).

## 8. Portfolio, constraints, costs

- Signal evaluation: decile L/S (extraction §30).
- Institutional L/S (US, p.31; regions, p.46; E-P2-24): market neutral, 2x
  leverage, target vol 4%, max stock 1.5%, beta ≤0.1, sector ≤10%,
  country ≤10% (regions), turnover 60% one-way/month, cost 20 bps one-way,
  10% of 20-day ADV, US$100m start 1995/1999.
- Long-only (E-P2-25): Russell 1000 benchmark, TE 2.5%, beta ±0.1, sector
  ±10%, 30% one-way/month, 20 bps, 10% ADV, $100m.
- Small regions with ADV: turnover 30% one-way (E-P2-26).
- Costs: flat 20 bps one-way everywhere (CR-013). Borrow: none modeled
  (extraction §35; ASSUMED frictionless — A-G011-19 applies).
- Risk model/optimizer identity NOT_DISCLOSED (A-004 substitute).

## 9. Validation periods and acceptance targets

- v1 out-of-sample check: Jun–Dec 2012 (boundary per CR-024: default OOS
  starts 2012-07).
- N-LASR2 signal backtests: US 1987–2012; regions per Fig 54 start dates to
  2012-11-30; optimized portfolios 1995/1999–2012 (E-P2-28). N-LASR2 itself
  has NO out-of-sample period in P2 (E-P2-28 note).
- Acceptance targets (E-P2-29; F-P2-10): US Russell 3000 rank IC avg/σ/
  risk-adj: raw 8.63/11.44/0.75; sector 8.13/7.42/1.10; sector+size
  7.84/6.48/1.21; sector+beta 8.23/6.20/1.33; s+s+b 7.78/5.50/1.41;
  +hedge 7.73/4.76/1.62 with 95% hit rate; decile spread 2.95%/mo.
  Optimized after-cost regional Sharpes per Fig 62 (US 3.41 … Global 3.53).
  Monotone risk-adjusted improvement across neutralization layers is the
  key qualitative acceptance pattern (CR-004 test).
