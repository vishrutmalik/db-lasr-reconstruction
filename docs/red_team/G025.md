## 1. CI-007 boundary + ComponentICRecord forgery

- **Boundary asymmetry pinned** (`TestBoundarySemantics`): a
  `TrainingPeriod` with `target_end == fit_as_of` IS selectable (CI-011
  inclusive — the label realizes exactly at fit) and `+1 microsecond` is
  not; a `ComponentICRecord` with `target_end == as_of` is NEVER usable
  (CI-007 strict `<`). A 0.99-IC boundary record cannot move weights off
  50/50. The asymmetry matches the two criteria's letter; the pin stops a
  future "harmonization" from loosening CI-007. The implementer's own
  `test_ci007_future_and_boundary_records_never_enter` covers the weights
  side; the microsecond-grain selection boundary and the cross-criterion
  pin are new.
- **Backdated-`target_end` forgery** is undetectable at this layer by
  construction (the record's `target_end` IS the filter key). Production
  record construction is the G026/G029 walk-forward's duty; the LT-005
  fixture demonstrates the honest protocol (append each month's IC only
  after its weights are used; realization at `dates[t+1]` is then excluded
  at the `dates[t+1]` fit by strict `<`). Caller-integrity gaps that ARE
  checkable locally are ratcheted:
- **RT-G025-1 (ratchet, non-blocking):** contradictory duplicate records —
  same `(component, period_id, calendar_key)`, different IC — are silently
  averaged. Probe: 4 forged copies of a 0.90 IC for B alongside the honest
  0.10 drag B's weight from 0.50 to `0.74/0.84 ≈ 0.88`. Want: refusal on
  duplicate record keys (the substrate already refuses duplicate period ids
  in `PeriodHistory` — same discipline).
- **RT-G025-2 (ratchet, non-blocking):** `calendar_key` is caller-asserted
  and never cross-checked against the record's own dates — a July-realized
  outcome forged with key `"02"` enters the February bucket undetected.
  Want: records carry `label_date` and the key is derived/validated.
- **Key-vocabulary mismatch pinned** (`"2"` vs `"02"`): matches nothing,
  degrades to permanent equal weights; the only guard — the A-G025-02
  fallback log — is pinned so the degradation can never become silent.
- **Wrong-year February**: NOT a defect — P1-25's expanding
  per-calendar-key mean pools ALL prior Februaries by design (OQ-P1-06 /
  A-G011-16); pinned as documented behavior
  (`test_all_prior_years_share_one_calendar_bucket`, hand-computed
  0.25/0.75).

## 2. Selector leakage

- **Trailing/previous at the lag boundary**: `target_end == fit_as_of`
  inclusion is CI-010/CI-011-correct (label complete at fit; the
  walk-forward decision at t trains on windows ending ≤ t). Verified
  end-to-end through `train_ensemble` (§7).
- **Seasonal anchors** (OQ-P4-14): both arms hand-checked; `target_month`
  December wraps to January (unit-covered); the realized filter excludes
  the current year's anchor month while its window is open (the CI-011
  clause, unit-covered). Leap-February is inert (matching is by `.month`).
  Month with no history drops visibly (`TrainedEnsemble.dropped` +
  warning, unit-covered).
- **min-history bypass**: only the evidenced policy id exists; unknown ids
  are refused at BOTH the config and canonical-schema paths
  (unit-covered). No bypass found.
- **HedgeBackcast honesty**: the series is caller-supplied and the
  caller-honesty assumption IS documented (selectors.py module + class
  docstrings name the G030/G033 DAG duty; CI-008's scope note says "G025
  interface"). Probes:
  - restated-metric attack: a realized period's metric rewritten with
    "future knowledge" silently changes the hedge set — pinned as the
    documented-assumption demonstration
    (`test_selector_faithfully_follows_a_restated_series`);
  - **RT-G025-3 (ratchet, non-blocking):** no knowledge stamps on
    `backcast_metrics` — want stamped backcast records validated against
    `fit_as_of` when G030/G033 deliver the builder. Routed: G030/G033.
  - window locality: post-fit metrics AND out-of-window metric changes are
    inert (`test_window_locality_out_of_window_metrics_are_inert`).
  - **RT-G025-4 (ratchet, non-blocking):** a lookback longer than realized
    history silently shrinks the backcast window (E-P2-19's 12-year
    backcast can become 4 months) — the tail selectors warn under
    A-G025-04 and have a strict arm; `HedgeBackcastSelector` has neither.

## 3. Fallback gaming (A-G025-02/03)

- **Withholding attack quantified**
  (`test_withholding_a_bad_components_history_restores_equal_weight`):
  with full records B's floored weight is exactly 0.0; deleting B's
  records flips the date to equal weights, handing B 0.5. This is the
  documented P1-25 generalization; the only guard is the fallback log —
  pinned. Production record supply is one code path (G026), so
  selective-withholding requires a dishonest caller; acceptable with the
  RT-G025-1/2 ratchets on record integrity.
- **Adversarial ties**: identical positive means produce equal weights via
  the NORMAL path with zero fallback log lines (pinned — a spurious
  fallback would mask degradation). Exactly-zero floored mass logs
  A-G025-03 (pinned). All-tied hedge metrics: "worst half" degenerates to
  the documented `(metric, period_id)` convention, permutation-invariant
  (pinned).

## 4. Composite exclusion / score-censoring (A-G025-08)

- **Censoring bias quantified**
  (`test_censoring_bias_is_real_and_the_exclusion_is_logged`): withholding
  one component's scores for the 3 worst of 10 names removes them from the
  composite and shifts the surviving mean by exactly +1.5 (survivorship
  shape). Reachable only under `propagate_nan` (under `h_zero` every
  expert scores every security). The shipped ledger is the A-G025-08 count
  log — pinned. The exclusion is honest-direction (names are dropped, not
  imputed) and `score_experts` separately logs per-expert unscored counts.
- **RT-G025-5 (ratchet, non-blocking):** a component floored to weight
  0.0 contributes nothing to the composite yet still gates coverage —
  names missing only from the inert component are censored. Want:
  exclusion restricted to `weight > 0` components, or a structural
  exclusion ledger in the return contract (INFO logs are not
  machine-auditable by G026/G028).

## 5. Zscore degeneracy cap (grant c)

- **Boundary exact-arithmetic pin**
  (`test_spread_just_below_the_cap_zeroes_just_above_standardizes`): at
  n=4, max≈1 (cap ≈ 4·eps), a 6-eps two-cluster spread (std = 3·eps)
  zeroes; a 10-eps spread (std = 5·eps) standardizes to exact ±1. Both
  sites (features definition + combine's lock-step copy) agree.
- **Mixed-magnitude attack defused**: a 1e15 outlier inflates the cap to
  ~0.9 but the std includes the outlier's ~4.3e14 deviation — normal-name
  ordering survives (pinned). The cap cannot wrongly zero a panel whose
  dispersion is dominated by an outlier, because that same outlier
  dominates the std.
- **inf/NaN poison defused**: ±inf/NaN are excluded by the coverage rule
  BEFORE the cap is computed (`_covered` / `math.isfinite`) — an inf name
  cannot drive tolerance to inf and zero the honest names (pinned).
- **RT-G025-6 (ratchet, non-blocking):** the cap grows linearly in n while
  summation round-off grows ~sqrt(n): at n=4096 a genuine 2048-ulp
  two-cluster dispersion (unambiguously distinct doubles) is zeroed. Honest
  direction (information dropped, never fabricated ±1s — the original
  defect), but the doc's "numerically indistinguishable from a constant
  cross-section" claim is false for wide panels. Want a ~sqrt(n)-scaled
  cap. Materiality today: nil for real H-score dispersions (many orders of
  magnitude above the cap); recorded so the claim and the code converge.

## 6. Stamps, refusals, visible drops (CI-006)

- **Poison-block attack through `train_ensemble`**
  (`TestTrainEnsemblePIT`): a label-inverted block realizing 1 second
  after the fit is invisible to every expert; all `train_max_target_end` /
  `train_max_knowledge_time` stamps ≤ `fit_as_of`. The same block at
  exactly `fit_as_of` is legitimately the most recent realized period and
  stamps at the bound (accepted by `FittedModel`'s CI-006 `<=` check).
  Transitivity holds by construction: `max_knowledge_time <= target_end`
  (PeriodBlock refusal, delisting-backfill shape — re-pinned) and
  `target_end <= fit_as_of` (selection) imply knowledge ≤ fit.
- Partial stamps yield `None`, never a fabricated bound (unit-covered);
  stamped bounds with missing `fit_as_of` are refused in `FittedModel`.
- Drops are visible: seasonal/hedge empty selections land in
  `TrainedEnsemble.dropped` with reasons + warning; all-dropped is a hard
  error; `score_ensemble` refuses weights that don't cover exactly the
  trained experts (dropped experts must be re-weighted upstream visibly).
- `ic_window='trailing_k'` through config is refused naming A-G025-07
  (pinned with the assumption id; the schema Literal admits the VALUE, so
  the runtime refusal is the only guard — do not remove it).
