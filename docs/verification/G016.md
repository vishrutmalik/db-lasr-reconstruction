   `numpy.random.*` calls but not, e.g., `numpy.random.default_rng`,
   `numpy.random.binomial/poisson/exponential/gamma/beta/geometric/
   multivariate_normal/bytes`. Extend the list (or add a grep-based unit
   test over `src/lasr`) when real code lands at G017+; `default_rng` needs
   an explicit policy call (it creates a Generator but bypasses the
   single-root + `spawn()` rule).
2. **Console script is a forward reference.** `lasr = "lasr.cli:main"` will
   raise at invocation until G029 implements `main`. Documented in-file and
   in the PR; acceptable, but G029's acceptance should include an
   entry-point smoke test.
3. **Docstring-only guard is set-based.** `test_package_imports` catches
   missing/extra packages and missing docstrings, but not logic added
   alongside a docstring; the G017 import-rule suite
   (`tests/unit/architecture/test_import_rules.py`) should close this.
4. `.gitignore` gained two explanatory comment lines beyond the strict
   ratified hunks — content-neutral, keep.
5. Proposal §4 says hypothesis CI profile has "fixed seed +
   `derandomize=True`"; implementation relies on `derandomize=True` alone
   (which makes the seed moot). Acceptable interpretation; note it if the
   proposal text is ever treated as normative letter.
