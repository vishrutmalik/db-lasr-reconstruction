## Non-blocking recommendations

1. **Python privacy residual (documented, not a defect):** a kernel can
   reach `ctx._pit` by private-attribute access and issue an unbounded
   as-of query; values so obtained would carry legitimate-looking stamps.
   Python offers no enforcement; the structural bound is the public API +
   in-repo review of registered kernels. Recommend a ruff banned-api
   (TID251) entry forbidding `PitStore`/`ctx._pit` in `features/library.py`
   kernels, and note the G029 training-batch leakage scan as the runtime
   backstop.
2. `size_neg_log_mcap.availability = "derived"` vs field_mapping §5.6
   classing "−Market Cap" as *direct*: defensible (the library applies a log
   transform, not bare negation), but worth one clarifying word in the
   evidence_source string.
3. CI-020(a) other-date test is tautological given the one-cross-section
   API (the criterion's "by construction" reading applies; per-date locality
   of the STORED layer is additionally covered by the engine PIT probes).
   No action required; recorded for the G030 within-cell owner.
4. Worktree copy of goals.md shows G022 IN_PROGRESS (main has
   IN_VERIFICATION) — coordination drift only; not part of the branch diff.
