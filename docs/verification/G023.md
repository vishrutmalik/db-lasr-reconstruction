  `window_end <= decision_time.date()` per record; min-history/degenerate
  sigma → ineligible row, never a fabricated denominator.

  after window) change nothing (hypothesis property test + my probes).
- Overlap is recorded per row (`OVERLAP_PERMITTED`), so downstream folds
  (G026) inherit the required purge width and embargo on every record.

## Non-blocking recommendations

1. `overlap.overlap_set_size` is computed from retained *candidate* grid
   points before it is known which points actually emit records; a neighbor
   that ends up emitting zero rows still counts. Metadata precision only —
   no leakage vector; tighten when G026 consumes the field.
2. `embargo_horizons` accepts any value ≥ 0 (e.g. 0.5 → sub-horizon
   embargo) with no provenance/warning tag; CI-015(b) is satisfied by the
   default (1.0) and by configurability, but a sub-1.0 setting for an
   overlapping family deserves a named-config warning at the VersionSpec
   layer (G026/G032/G033 can add it).
3. CR-025's register suggests a random-panel equivalence test (labels
   identical under `cell_return_transform` none vs rank). The implementation
   makes the equivalence structural (labels never consume the transform), so
   the risk is nil, but the literal register test is not present — add it
   when convenient to guard against future refactors.
4. Engine stamps `feature_observation_time = knowledge_cutoff =
   max_feature_knowledge_time = model_fit_time = signal_time =
   decision_time`. Correct for a feature-less target build and honestly
   documented, but G024/G026 MUST override fit/signal/knowledge stamps when
   features join — tracked by the stated limitations; do not let the
   placeholder survive into the training-set join.
5. `weekly_volatility` computes only consecutive-week returns (a missing
   close drops that pair rather than bridging the gap) — conservative and
   documented, but the weeks_used accounting means a gappy stock's σ window
   is shorter than `window_weeks`; consider recording the gap count in the
   spec string for the G037 audit.

## Limitations honesty (all five claims verified accurate)

1. *Fit-time stamping*: `model_fit_time = decision_time` placeholder;
   engine docstring says G026 stamps real fit times. Accurate.
2. *max_feature_knowledge placeholder*: set to `knowledge_cutoff` pending
   the feature join. Accurate (engine.py line 500).
3. *sample_window_tags*: passthrough default `("unassigned",)`; tagging is
   the ensemble layer's job (CI-011/G025). Accurate.
4. *Persisted purge_status*: only CLEAN / OVERLAP_PERMITTED are ever
   emitted; fold-level PURGED/EMBARGOED statuses belong to G026. Accurate.
5. *No full store round-trip*: records are returned in memory as validated
   rows; no parquet/store persistence test in this goal. Accurate.
