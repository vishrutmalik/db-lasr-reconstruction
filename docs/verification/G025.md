### Non-blocking (owner-routed)

1. **NB-1 (features owner / G022-successor; also G025 docstring precision):**
   the definition site `transforms.zscore` is insertion-order dependent at
   the ~1–2 ulp level (numpy accumulates in dict insertion order), while
   `zscore_with_universe` sorts and is order-invariant (verified over 300
   shuffles). Consequently the combine.py claim of being "value-identical"
   to the definition site holds only when insertion order equals sorted
   order; my 200-random-vector probe found last-ulp divergences whenever
   keys like S10/S11 break lexicographic = insertion. The lock-step PIN
   tests (3 keys, sorted) cannot catch this. Impact: ulp-scale, no criterion
   affected; but CI-043's letter ("permuting … changes no output") is
   violated at the definition site — pre-existing G022 surface, NOT
   introduced by this PR (grant (c) changed only the degeneracy branch).
   Suggested: sort `_covered` output at the definition site, or soften
   "value-identical" to "same rule, ulp-equivalent"; extend the pin to n>10
   unsorted keys.
2. **NB-2 (G030/G033; converges with red-team RT-G025-4):**
   `HedgeBackcastSelector` with realized history shorter than
   `lookback_periods` silently uses the shorter window — no warning, unlike
   the tail selectors' A-G025-04 discipline (probe: lookback 500 over 89
   realized periods → 44 picked, no log). Bottom-half-of-what-exists may be
   defensible, but it should be as visible as the trailing-window case.
3. **NB-3 (G029 wiring / G025-successor; converges with RT-G025-5):**
   `combine_component_scores` intersects coverage over ALL components
   including weight-0.0 ones — a security missing only from a floored-to-zero
   component is excluded although that component contributes nothing. The
   docstring says "missing from ANY weighted component"; behavior is "any
   component". Conservative (never imputes) but shrinks the composite
   universe unnecessarily under propagate_nan + floored IC weights.
4. **NB-4 (G029 wiring):** calling `combine_component_scores` directly with a
   component whose score map is empty yields a silent empty composite `{}`
   (the `score_ensemble` path is protected — `score_experts` refuses an
   all-missing expert). A typed refusal or log at the combine boundary would
   close the direct-call surface.
5. **NB-5 (cosmetic):** "first 13 fits equal-weighted" (LT-005 test class
   docstring + PR body) — measured: 12 equal fits, first IC-driven at fit
   index 12. The assertions (`weights_log[0]` equal; any of
   `weights_log[13:]` unequal) are unaffected.
6. **NB-6 (features owner, jointly with red-team RT-G025-6):** the A-G025-05
   cap `max|x|·n·eps` scales linearly in n; at n≈3000 it reaches ~6.7e-13
   relative spread, and the red-team's ratchet shows a genuine 2048-ulp
   two-cluster dispersion zeroed at n=4096. Error direction is honest
   (degenerate→0.0, never fake ±1) and real score dispersion sits orders of
   magnitude above; a ~√n-scaled cap would be tighter. Already ratcheted as
   a strict xfail; no action needed inside G025.
7. **NB-7 (cosmetic, PR body only):** "Baseline main: 2056 tests" — measured
