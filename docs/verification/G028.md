1. **Grant-path discrepancy (charter error, confirmed):** the grant text
   said `docs/methodology/testing_strategy.md`; no such file exists —
   the project's only testing-strategy doc is
   `docs/architecture/testing_strategy.md`, and the amendment there is
   exactly one row (1+/1-), the CI-009 coverage one-liner the grant
   described. Implementer landed it at the correct real path; the
   charter's path was wrong. Orchestrator: record the corrected path.
2. **Dedup depth coverage:** the branch's N12 test exercises depth-2
   duplication (test_steps=2); the red-team case is "up to test_steps
   (=3) folds". My depth-3 probe passes; recommend promoting it (or a
   test_steps=3 variant) into the unit suite.
3. **Empty-prediction-set panel:** `build_scoring_panel` on an empty set
   returns an empty panel with `horizon_steps` silently defaulting to 1
   (`horizons[0] if horizons else 1`) instead of a typed refusal.
   Downstream metrics refuse, so nothing silent escapes, but the default
   is a small hidden-defaults wrinkle worth a refusal.
4. **NaN skip reason labeling:** non-finite cross-sections are ledgered
   as `SkipReason.DEGENERATE` (detail names non-finite positions); a
   dedicated `NON_FINITE` reason would be more precise.
5. **NOT_AVAILABLE now-satisfiable ruling (routing note):** G024 merged
   to main AFTER this branch froze (branch base f863b1d) and its
   `FittedModel.boost.selected_factor_ids` per fit now makes
   `factor_selection_stability` inputs producible; `selection_scores`
   could plausibly feed `feature_family_exposure` (with the G022 family
   map). The G028 interfaces are caller-input functions (they compute
   when fed; NotAvailable only when the caller passes None), so they are
   STILL legitimate as shipped — the wiring belongs to the consumer.
   Route to G029: supply `selections_by_fit` from G024 artifacts and
   decide the family-weight source. `submodel_contribution` (G025,
   unmerged) and beta/ADV inputs remain legitimately NOT_AVAILABLE.
6. **NW over gapped series:** skipped dates leave gaps in the IC series;
   `newey_west_se` treats the series as contiguous. Standard practice,
   but worth one docstring line when a sparse panel is expected.
7. **fold_id tie-break unexercised on real data:** duplicate groups from
   the real runner never share `model_fit_time`, so the max-fold_id
   tie-break is exercised only implicitly. Deterministic by
   construction; a unit fixture with a manufactured tie would pin it.
8. **LT-004 activation seam (routing note):** LT-004 names G028 in its
   activation list ("leakage-diagnostics report flags single-feature
   |IC| > threshold as suspected_leak"); no such flag interface exists in
   reporting yet. Activation is G029/G037-gated so this is not a G028
   acceptance failure, but the flag will need a home (ic_series is the
   natural substrate). Route to G029/G037 owner.
9. **hit-rate zero convention:** IC_t == 0.0 counts as a miss (strict
   `> 0`). Documented in A-G028-02's comment; include the boundary in
   the register entry when A-G028-01..10 are registered.
