## Non-blocking recommendations

1. **NB-1 (hardening, owner: G035 implementer or G037 red-team keeper):**
   `_prepare` gates on `risk_model.is_substitute` but never cross-checks
   `risk_model.manifest.substitute`. A user-authored RiskModel reporting
   `is_substitute=True` while returning a manifest with `substitute=False,
   assumption_id=None` is accepted, and that unlabeled manifest is copied
   verbatim onto `Level3Result.risk_model_manifest`. Not reachable from any
   config or from shipped code (`ShrinkageRiskModel` hardcodes the label, and
   `RiskModelManifest.__post_init__` blocks `substitute=True` with a wrong id
   — though not `substitute=False` itself). One-line fix: refuse when
   `risk_model.manifest.substitute != risk_model.is_substitute`.
2. **NB-2 (documentation nuance, owner: G035 implementer):** the
   effect-separation additivity is telescoping — exact to ≤1 ulp (worst
   4.3e-19 over 20 seeds), not literally bit-identical on every input; the
   test pins `abs=1e-15`. The `level3_compare` docstring's "holds by
   construction" is accurate at that tolerance; consider saying "to float
   rounding (≤1e-15, pinned by test)" to preempt a red-team nit.
